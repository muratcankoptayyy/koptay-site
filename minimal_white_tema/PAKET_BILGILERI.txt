```bash

2. "Birlikte aç" → Chrome/Edge
3. Sayfalar arası geçiş yap (sidebar linkleri çalışır)
4. Tasarımı incele
```

### Örnek 2: Buton Kopyalama

```bash

2. "BUTONLAR" bölümünü bul

```

### Örnek 3: Dashboard Oluşturma

```bash
1. dashboard_minimal.html → Aç
```

## 🎨 Tema Özellikleri Hatırlatıcı

### ✅ Kullanılacaklar

```css
Renkler:     gray-900, gray-700, gray-500, gray-300, gray-200, white
Fontlar:     font-light (çoğu), font-medium (vurgu), font-normal
Çerçeve:     border-gray-300 (ana), border-gray-200 (ince)
Input:       border-0 border-b (sadece alt çizgi)
Buton:       bg-gray-900 (primary), border (secondary)
Boşluk:      p-12, gap-8, mb-16 (bol whitespace)
```

### ❌ Kullanılmayacaklar

```css
rounded-*    → Keskin köşeler (NO rounded)
shadow-*     → Flat tasarım (NO shadow)
bg-blue-*    → Siyah-gri palet (NO color)
font-bold    → İnce fontlar (font-light/medium)
```

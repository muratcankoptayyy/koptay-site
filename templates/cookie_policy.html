1. Çerez Nedir?

Çerezler (cookies), web sitelerini ziyaret ettiğinizde cihazınıza (bilgisayar, tablet, telefon) kaydedilen küçük metin dosyalarıdır. Çerezler, web sitesinin size daha iyi hizmet sunmasını sağlar.

2. Neden Çerez Kullanıyoruz?

  • Oturumunuzu açık tutmak (giriş yapılı kalmak)
  • Tercihlerinizi hatırlamak (dil, tema)
  • Site performansını analiz etmek
  • Kullanıcı deneyimini iyileştirmek
  • Güvenlik sağlamak

3. Kullandığımız Çerez Türleri

🔐 Zorunlu Çerezler

Platformun çalışması için gerekli çerezlerdir. Bu çerezler devre dışı bırakılamaz.

  • session - Oturum yönetimi (Flask session cookie)
  • csrf_token - Güvenlik (CSRF koruması)
  • remember_token - "Beni hatırla" özelliği

📊 Analitik Çerezler

Site kullanımını analiz etmek için kullanılır. (Devre dışı bırakılabilir)

  • _ga - Google Analytics ID (2 yıl)
  • _gid - Google Analytics oturum (24 saat)
  • _gat - İstek hızı sınırlama (1 dakika)

⚙️ Fonksiyonel Çerezler

Tercihlerinizi hatırlamak için kullanılır.

  • theme - Karanlık/aydınlık mod tercihi
  • language - Dil tercihi
  • cookie_consent - Çerez onay durumu

4. Çerez Detayları

Çerez Adı Amaç Süre Tür
session Oturum yönetimi Oturum süresi Zorunlu
remember_token Beni hatırla 30 gün Zorunlu
_ga Google Analytics 2 yıl Analitik
theme Tema tercihi 1 yıl Fonksiyonel

5. Çerezleri Nasıl Kontrol Edebilirsiniz?

Tarayıcı Ayarları:

  • Chrome: Ayarlar → Gizlilik ve güvenlik → Çerezler
  • Firefox: Seçenekler → Gizlilik ve Güvenlik → Çerezler
  • Safari: Tercihler → Gizlilik → Çerezler
  • Edge: Ayarlar → Gizlilik → Çerezler

⚠️ Uyarı: Zorunlu çerezleri devre dışı bırakırsanız platform düzgün çalışmayabilir (örn: giriş yapamayabilirsiniz).

6. Google Analytics Opt-Out

Google Analytics çerezlerini devre dışı bırakmak için:

  • Google Analytics Opt-out Browser Add-on yükleyin
  • Tarayıcınızda "Do Not Track" özelliğini aktifleştirin

7. Üçüncü Taraf Çerezler

Platformumuzda kullanılan üçüncü taraf servisleri:

  • Google Analytics: Site kullanım istatistikleri
  • Google Maps: Harita ve konum servisleri
  • Tailwind CDN: CSS framework
  • Google Fonts: Web fontları

Bu servislerin kendi çerez politikaları vardır.

8. Çocukların Gizliliği

Platformumuz 18 yaş altı kullanıcılara yönelik değildir. Bilinçli olarak 18 yaş altından çerez toplamıyoruz.
